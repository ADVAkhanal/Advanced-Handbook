About this Portal

What this is

An internal, self-contained employee handbook for Advanced Companies. Every answer is drawn directly from the handbook text — nothing is sent to any outside service.

How to use it

  • Type a full question ("How much PTO do I get?") or a keyword ("overtime") and press Ask.
  • The top match shows a short answer pulled from the handbook plus the section number for reference.
  • Click any section card to expand the full policy text.
  • Browse by category using the sidebar on the left.
  • Use / to jump to the search box, Esc to clear it.

If you can't find an answer

The portal will tell you when it isn't confident. When that happens, contact your HR representative directly — they are the final authority on policy questions.

Privacy

This page runs entirely on your computer. No questions, searches, or activity are logged or sent anywhere. The page works without internet access.

How to Deploy Internally

The handbook is a single self-contained HTML file. Pick whichever option fits your environment — no servers, build tools, or internet are required to use it.

Option 1 — Shared network drive (simplest)

  1. Copy Advanced_Handbook_Dashboard.html to a read-only shared folder (e.g., \\fileserver\shop\Handbook\).
  2. On each shop computer, create a desktop shortcut that points to the file. Right-click the desktop → New → Shortcut → paste the UNC path.
  3. Rename the shortcut to Employee Handbook and pick a recognizable icon.

Option 2 — Intranet web server (IIS / nginx)

Place the file in a static-content folder served over HTTP. No backend code is needed.

IIS: drop the file into C:\inetpub\wwwroot\handbook\ and browse to http://intranet/handbook/Advanced_Handbook_Dashboard.html.

nginx: add a location block that serves the file, e.g.:

location /handbook/ {
  alias /var/www/handbook/;
  index Advanced_Handbook_Dashboard.html;
}

Option 3 — Browser homepage / kiosk

  • Set as homepage via Group Policy or each browser's settings so the handbook opens automatically.
  • Kiosk shortcut: launch Edge or Chrome with the file path, e.g.
    msedge.exe --kiosk "\\fileserver\shop\Handbook\Advanced_Handbook_Dashboard.html"

Updating the handbook

To publish a new version, replace the file in the shared location. Every shop computer will see the new version next time they open it — no reinstall required.

Offline guarantee

The page uses local data only. Google Fonts are loaded as a non-blocking enhancement; if internet is unavailable, the page falls back to system fonts and remains fully functional.
